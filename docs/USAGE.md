# MakeBook Studio 사용 흐름

## 1. 책 규격
오른쪽 패널의 페이지/책 설정에서 신국판 152×225mm, 도련, 안전여백, 세네카 폭, 출력 DPI를 수정합니다.

## 2. 겉표지
`겉표지+세네카` 템플릿은 한 장의 펼침면 안에 `뒷표지 | 책등 | 앞표지`를 표시합니다. 붉은 선은 재단/경계, 녹색 점선은 안전여백입니다.

### 샘플 이미지 품질을 유지하는 권장 방식
1. 이미지 생성 모델에서 카세트·이어폰·스티커 같은 **그래픽 자산만** 만듭니다.
2. MakeBook에서 `배경` 또는 `이미지`로 올립니다.
3. 제목/부제/본문/트랙 번호는 `텍스트` 요소로 별도 조판합니다.
4. 레이어 순서, 혼합 모드, 투명도, 회전을 조정합니다.
5. 완성 후 300dpi PDF를 출력합니다.

## 3. 이미지 위 조판
- `▣ 배경`: 현재 페이지 크기로 자동 배치하고 잠급니다.
- `▧ 이미지`: 자유 이미지 레이어로 추가합니다.
- `T 텍스트`: 이미지 위에 실제 텍스트를 배치합니다.
- `□ / ○ / ─`: 카드, pill, divider 등을 직접 만듭니다.

## 4. 세네카
세네카 폭(mm)을 수정하면 겉표지 펼침면 폭이 즉시 바뀝니다. 실제 인쇄소의 용지/제본 사양에서 받은 책등 폭을 입력하는 것이 가장 정확합니다.

## 5. 전자책
전자책은 `앞표지 단면 → 반표제 → 속표지 → 속표지 뒷장 → 내용 → 뒷표지 단면` 순서로 페이지를 구성한 뒤 EPUB3를 출력하십시오. 시각 디자인 보존이 목적이므로 현재 EPUB은 `pre-paginated fixed-layout` 방식입니다.

## 6. 단축키
- Ctrl/Cmd+Z: 실행취소
- Ctrl/Cmd+Y: 다시실행
- Ctrl/Cmd+D: 선택 요소 복제
- Ctrl/Cmd+C/V: 요소 복사/붙여넣기
- Delete/Backspace: 요소 삭제
- 방향키: 미세 이동
- Shift+방향키: 5mm 이동

## 7. 프로젝트 보존
고해상도 이미지와 커스텀 폰트가 들어간 프로젝트는 브라우저 저장용량을 초과할 수 있습니다. 중요한 시점마다 `프로젝트 저장`으로 `.makebook.json` 파일을 별도 보관하십시오.
