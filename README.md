# MakeBook Studio

샘플 이미지 수준의 시각 품질을 실제 책/전자책 조판에 최대한 유지하기 위한 브라우저 기반 출판 디자인 스튜디오입니다.

## 현재 구현

- 신국판 기본값 `152 × 225mm`, 도련/안전여백/세네카 폭 편집
- **겉표지 전체 펼침(뒷표지 + 세네카 + 앞표지)** 전용 가이드
- 전자책 앞표지/뒷표지, 반표제, 속표지, 속표지 뒷장(판권), 본문, 장 시작면, TRACK 템플릿
- 이미지 업로드 후 **이미지 위에 텍스트/도형/다른 이미지를 레이어 조판**
- 드래그/리사이즈, mm 단위 X/Y/W/H 직접 입력, 회전, 투명도, 혼합 모드
- 텍스트 내용/폰트/크기/굵기/행간/자간/색/정렬/배경/테두리 수정
- 로컬 폰트(TTF/OTF/WOFF/WOFF2) 업로드 및 프로젝트 내 포함
- 이미지 cover/contain/fill, 배경 이미지 자동 풀페이지 배치/잠금
- 레이어 앞뒤 이동, 잠금/숨김/복제/삭제
- 좌/중앙/우 및 상/중앙/하 페이지 정렬
- 스냅, 그리드, 안전여백/도련/세네카 가이드
- 페이지 추가/복제/삭제/순서 변경
- Undo/Redo, 복사/붙여넣기, 키보드 미세 이동
- 브라우저 localStorage 자동 저장
- `.makebook.json` 프로젝트 저장/복원
- 현재 페이지 고해상도 PNG 출력
- 전체 **고정 레이아웃 PDF** 출력
- 현재 페이지 브라우저 벡터 인쇄/PDF 출력
- 전체 **EPUB 3.0 fixed-layout** 코딩/출력 (`package.opf`, `nav.xhtml`, rendition metadata 포함)
- GitHub Pages 배포 워크플로

## 실행

Node.js 22 권장.

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

## 디자인 품질 전략

이 프로젝트는 AI 샘플 이미지를 그대로 한 장으로 쓰는 대신, 샘플의 그래픽 자산을 PNG/WebP/SVG로 분해해 업로드하고 텍스트를 실제 조판 레이어로 올리는 방식을 지향합니다. 카세트/이어폰/스티커/배경 질감은 이미지 자산으로, 파형/재생 UI/선/도형/타이포는 편집 가능한 레이어로 구성하면 샘플의 감성과 수정 가능성을 동시에 확보할 수 있습니다.

## PDF / EPUB

- `PDF`: 모든 페이지를 지정 DPI로 렌더링해 페이지별 실제 mm 규격의 PDF로 묶습니다.
- `벡터 인쇄/PDF`: 현재 페이지만 브라우저 Print CSS로 출력해 텍스트를 브라우저 벡터 출력에 맡깁니다.
- `EPUB3`: 페이지를 고해상도 이미지로 렌더링해 pre-paginated fixed-layout EPUB3를 생성합니다. 샘플 이미지와 동일한 레이아웃 보존이 목적일 때 사용합니다.
